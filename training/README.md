# Reproducible demand data and evaluation

`original/Untitled0.ipynb` is a byte-for-byte copy of the Colab notebook found
at `/Users/krishanshverma/Downloads/Untitled0.ipynb`. The notebook creates a
synthetic 365-day demand sequence using NumPy seed 42. It builds lag and rolling
features from past demand, drops the first seven rows, and later adds
`day_of_week = (day - 1) % 7`. It trains V1 and V2 with `LinearRegression` on
the first `int(len(df) * 0.8)` rows and evaluates on the remaining rows in
chronological order. The previous-day baseline is the held-out
`previous_day_demand` column.

## Regenerate the notebook dataset

From the project root, with the project environment active:

```bash
python training/generate_dataset.py
```

This exports `training/synthetic_demand.csv` (358 usable rows with columns
`day`, `demand`, the three V1 features, and `day_of_week`). The CSV is derived
from the deterministic generation code in the notebook; it is not observed
sales data. The notebook itself did not save a dataset CSV; its dataset existed
in memory, so the CSV is regenerated by rerunning the notebook's generation
logic rather than recovered from notebook outputs.

## Evaluate the preserved model artifacts

```bash
python training/evaluate_models.py
```

The evaluator loads `demand_model.joblib` (V1) and
`demand_model_v2.joblib` (V2), applies both to the same held-out chronological
rows, and calculates the previous-day baseline. It does not train, overwrite,
or save any model. It prints full precision, the notebook-reported values, and
the measured-minus-reported differences. The notebook's displayed rounded
results are V1 2.22, V2 2.09, and previous-day baseline 2.31 units/day.

The scripts use the project's existing NumPy, pandas, joblib, and
scikit-learn dependencies. The Streamlit app continues to load V2 separately;
these scripts are not invoked by the app.
